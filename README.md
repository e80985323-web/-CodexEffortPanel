# Codex 思考强度面板

给 **Codex 桌面版（Microsoft Store 版）** 的「思考强度」滑条解锁最高档，并把最高档的显示文字改成 **Ultra**，同时让滑块拉到顶时出现 **紫色等离子 + 粒子爆发**特效。

**只改前端显示，不动模型路由、不动供应商、不动中继。**

```
    思考强度
    ├── 轻度
    ├── 中
    ├── 高
    ├── 极高
    ├── Ultra   ← 原本显示「最高」，且外接 API 模式下根本拉不到这一档
    └── ...
```

---

## 一键安装

> 前提：Windows 10/11，已从 Microsoft Store 安装 **Codex**，机器上有 **Python 3**（自带 tkinter）。

1. 下载本仓库（右上角 **Code → Download ZIP**，或 `git clone`）
2. 解压后**双击 `install.cmd`**
3. 桌面出现两个图标：
   - **Codex 思考强度** —— 面板（主要入口）
   - **Codex 启动(带补丁)** —— 启动器（可选）

安装脚本会自己检查 Python、拷文件、建快捷方式，**不碰注册表，不碰系统目录，不碰 Codex 安装包本身**。

### 没有 Python？

安装脚本会提示，并可以**自动调用 winget 安装**：

```powershell
winget install -e --id Python.Python.3.13
```

装完**关掉窗口重新双击 `install.cmd`**（PATH 要新窗口才生效）。

## 使用

双击桌面 **「Codex 思考强度」**，面板里 5 行状态：

| 行 | 含义 |
|---|---|
| 1. 模型目录 max 档位 | 让滑条能拉到最高档（给每个模型补上 `max`） |
| 2. 强度白名单 | `config.toml` 的 `enabled-reasoning-efforts` 含 `max` |
| 3. 紫光特效 | 拉到顶时滑块填充 蓝 → 紫 + 粒子爆发 |
| 4. Ultra 标签 | 最高档显示为 `Ultra`（中文界面） |
| 5. 包身份补丁 | 支撑 3、4 的底层补丁 |

**全绿 = 四项都已生效。**

四个按钮：

| 按钮 | 作用 |
|---|---|
| **刷新状态** | 重新检查，只读，不改任何文件 |
| **一键生效** | 打补丁（必要时自动重建可写副本） |
| **启动 Codex** | 先打补丁，再启动 Codex |
| **回退** | 把可写副本还原成原始文件（有二次确认） |

---

## ⚠️ 一定要知道的一件事

**Codex 是单实例程序。它正在运行时再点「启动 Codex」，补丁不会生效。**

原因：Codex 用单实例锁，第二次启动会被**转发给已经在运行的那个窗口**，不会加载新代码。面板会明确提示你这件事。

**正确顺序：**

```
先完全退出 Codex  →  再点「启动 Codex」
```

（或者直接双击桌面的「Codex 启动(带补丁)」，它启动前会自动打补丁。）

---

## 它到底改了什么

Codex 装在 `C:\Program Files\WindowsApps\...`，那份是 **TrustedInstaller 所有、只读的**。
所以补丁不打在安装包上，而是打在一个**可写的副本**上：

```
%LOCALAPPDATA%\Codex Profile Manager\WindowsAppsCache\<包名>\app
```

补丁分三层：

1. **配置层** —— 模型目录 JSON 补上 `max` 档位；`config.toml` 白名单加上 `max`
2. **asar 层** —— 改 `app.asar` 里的前端 JS：
   - 把「最高档」的判定从官方 `isMax` 改写成「滑条在顶档」
     （外接 API 模式下官方那条路永远不成立，所以紫光永远不出现）
   - 把 i18n 表里最高档的中文标签从 `最高` 换成 `Ultra`
3. **启动层** —— 设置 `CODEX_SPARKLE_ENABLED=false`，并跳过一处 MSIX 包身份调用，
   让这个没有包身份的副本能正常启动

> asar 补丁要求**等长字节替换**，所以 `Ultra` 后面补了一个空格凑长度（不会被渲染出来）。

---

## 更新后还有效吗

**有效，且是自动的。**

- Store 更新后**包目录名会变**（里面带版本号），启动器/面板用通配符查询自动发现新版本
- 补丁位置**按正则现推**，不硬编码 —— 新版本改了变量名也能自己找到
- 可写副本不存在时**自动重建**（首次约 3,498 个文件 / ~2.2 GB / 约 11 秒；之后是 0.0–0.2 秒）
- 标签补丁是**失败开放**的：万一新版本改了 i18n 表结构，最坏情况只是标签退回显示「最高」，**绝不会导致启动失败**

## 回退

**面板上的「回退」按钮**最省事（有确认弹窗，只影响它显示的那个版本）。

命令行等价物：

```bat
python codex-max-effects-patch.py restore --only 26.915.4065.0
```

**彻底卸载**：双击 `uninstall.cmd` —— 删安装目录、删两个快捷方式、还原 Codex 可写副本。
（不会卸载 Python，不会碰 Codex 本体。）

---

## 关于代理

本工具**不要求**代理。

如果你需要给 Codex 挂代理，在安装目录（`%LOCALAPPDATA%\CodexEffortPanel\`）放一个 `proxy.txt`，
第一行写代理地址，例如：

```
http://127.0.0.1:7897
```

「Codex 启动(带补丁)」会读取它，并做**代理健康检查**（探测 3 次，失败会提示你换节点）。
没有 `proxy.txt` 就直接启动，不加代理参数。

## 文件说明

| 文件 | 作用 |
|---|---|
| `CodexEffortPanel.pyw` | 面板 GUI（标准库 tkinter，零第三方依赖） |
| `codex-max-effects-patch.py` | 补丁引擎（版本无关，面板运行时加载它） |
| `launch-codex-default.cmd` | 便携启动器（自动发现 Codex + 可选代理） |
| `install.cmd` / `install.ps1` | 安装 |
| `uninstall.cmd` / `uninstall.ps1` | 卸载 |
| `docs/交付报告.md` | 完整交付报告（含验证证据） |

> **为什么是 `.pyw` 不是 `.exe`：** 补丁引擎必须能随 Codex 更新保持**可编辑**（它靠正则现推每个新版本的补丁位置）。
> 打包成 exe 等于把引擎焊死，以后想改就得重新打包。`.pyw` + 桌面快捷方式同样双击即用、**不弹黑框**，且零新依赖。

## 已知限制

1. **英文界面仍显示 `Max`** —— asar 补丁是等长字节替换，`Max`（3 字节）装不下 `Ultra`（5 字节），
   引擎会记录并跳过。中文界面已生效为 `Ultra`。
2. **只有中文（zh-CN）原本是「最高」**，`zh-HK` / `zh-TW` / `ja-JP` 等原本就是英文/日文 `Max`，未改动。
3. **Codex 正在运行时补丁不生效** —— 见上面的单实例说明。
4. 外接 API 模式需要你自己已经配好模型供应商（本工具**不**负责配供应商/中继）。

---

## 原理速览

外接 API 模式下，官方那条「紫光」路径**永远走不到**，因为：

- `isMaximum` 来自 ChatGPT 的 `lane` 数据，自定义模型目录**根本不带**这个字段
- `ultra` 档位卡在一个远程开关后面，而且中继会拒（HTTP 400）

所以补丁把「是否最高档」的判定改写成「**滑条是不是在顶档**」——
这样任何能用到 `max` 的模型，拉到顶都会出现紫光。

> `max` 本身是**上游合法且有效**的档位（实测 `{"reasoning":{"effort":"max"}}` → HTTP 200；
> 而 `ultra` → HTTP 400）。本工具只是把这个已经存在的档位**解锁到 UI 上**。
